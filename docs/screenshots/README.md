# 截图

这些**不是**上架截图 —— 是审核会遇到的边界状态的实拍存档，
iPhone 17 Pro Max 模拟器，1320 × 2868。

| 文件 | 状态 | 为什么留着 |
|---|---|---|
| `state-permission-denied.png` | 用户拒绝相册权限 | 审核员一定会试。有说明文字和「打开设置」按钮，不是空白页 |
| `state-clean-library-before-fix.png` | 干净相册（**修复前**） | 屏幕下面三分之二纯黑。`emptyState` 是死代码：判空用的是「行列表为空」，但「按 App 归类」那一行永远会追加，所以扫完之后永远不为空 |
| `state-clean-library-after-fix.png` | 干净相册（修复后） | 判据改成「有没有活要干」，现在会说「没有找到可清理的东西」 |

上架截图还没拍，卡在两件事上：

1. **名字要先定** —— App 名字出现在导航栏里，改名等于全部重拍
2. **演示素材** —— 不能用真实相册截图上架（那些图是公开的），需要一批合成演示照片

拍摄脚本已经写好：`fastlane/screenshots/capture.sh <演示照片文件夹>`，
